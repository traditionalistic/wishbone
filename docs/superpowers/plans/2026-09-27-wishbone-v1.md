# Wishbone V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** сквозной срез Wishbone — админка → Go-бэк (компилятор DSL, хранение, выдача, превью) → iOS и Android SDK рисуют три шоукейс-экрана одинаково, с DSL-логикой и фул моушеном.

**Architecture:** монорепо; `contract/` — нормативные данные (примитивы, stdlib, темы, иконки, шаблоны, conformance-векторы). Go компилирует исходник экрана (JSON-дерево + DSL) в JSON-AST, клиенты только интерпретируют AST. Реактивность — наблюдаемые ячейки платформы (Observation / snapshot state).

**Tech Stack:** Go 1.26 (net/http, pgx/v5, coder/websocket), Postgres 17; Swift 6.3 / SwiftUI iOS 18, SPM, Tuist (Playground), lottie-ios, RiveRuntime; Kotlin 2.3, Compose (BOM most), OkHttp, kotlinx.serialization, lottie-compose, rive-android; React 19 + TS + Vite, CodeMirror 6.

**Spec:** `docs/superpowers/specs/2026-09-27-wishbone-v1-design.md` — нормативна §2–§6. План на неё ссылается и её не переопределяет.

## Global Constraints

- iOS deployment target 18.0, Swift 6 language mode; Android minSdk 33, compileSdk 36, Kotlin 2.3.20, AGP 9.3.0, Gradle 9.5.0, Compose BOM 2026.02.01 (как в `~/projects/most`).
- Проводной формат — ровно §3.8 спеки; `format: 1`, `runtimeMin: "1.0.0"`, клиентский runtime `"1.0.0"`.
- Цвета и типографика только токенами; длительности в мс; `@radius.pill` = 9999.
- Числа — float64; приведение к строке — правило §3.6.
- Лимиты документа: ≤ 512 КБ, глубина ≤ 32, узлов ≤ 2000; бюджет прогона обработчика — 10 000 шагов.
- Значения полей форм и `args` write-операций не логируются.
- Комментарии в коде — по минимуму, только «почему»; сознательные упрощения помечаются `ponytail:`.
- Субагенты **не коммитят и не трогают git** (общий индекс); коммитит оркестратор после ревью.

## Фаза 2 — Go-компилятор (оркестратор)

### Task 2: `backend/internal/dsl` — лексер, парсер, типы, понижение

**Files:** `backend/go.mod`, `backend/internal/dsl/{lexer,parser,ast,types,check,lower,stdlib}.go` + `*_test.go`.

**Interfaces — Produces:**
- `dsl.ParseScript(src string) (*Script, []Diag)`, `dsl.ParseExpr(src string) (Expr, []Diag)`, `dsl.ParseStmts(src string) ([]Stmt, []Diag)`, `dsl.ParseType(src string) (Type, error)`.
- `dsl.Checker` с окружением (`Env`: имена стейта/computed/data/param/fn/handler/locals/instance-state, токены темы, драйверы) → типизированное дерево; `dsl.Lower*` → `json.RawMessage` форм §3.8.
- `Diag{Line, Col int; Msg string}`.

- [ ] Табличные тесты: приоритеты, интерполяция, единицы `ms/s`, лямбды, метод-сахар, ошибки типов (`"a" + 1`, `!3`, присваивание в computed, рекурсия fn), понижение в AST (golden).
- [ ] `cd backend && go test ./internal/dsl/...` — PASS. Commit.

### Task 3: `backend/internal/compile` + `cmd/wbc`

**Files:** `backend/internal/compile/{compile,templates,validate,contract}.go` + тесты; `backend/cmd/wbc/main.go`.

**Interfaces — Produces:**
- `compile.LoadContract(dir string) (*Contract, error)` — примитивы, stdlib, темы, иконки, шаблоны, операции.
- `compile.Screen(c *Contract, src []byte, rev int) (doc json.RawMessage, meta Meta, diags []Diag)`; `Diag{Path, Line, Col, Msg}`; `Meta{RuntimeMin string; Ops []string; Data []DataDecl}`.
- `wbc conformance -contract ../contract` → `contract/conformance/compiled/*.json`; `wbc compile <screen.json>` → stdout.

- [ ] Тесты: раскрытие шаблона (param, slot, emit, локальный стейт в `repeat`, префиксы id/таймлайнов), неизвестный prop/токен/иконка/операция → диагностика с путём, дубликат id, лимиты, `bind`-сахар.
- [ ] `go run ./cmd/wbc conformance` генерирует `compiled/`; `go test ./...` PASS. Commit.

**Files:** `android/{settings.gradle.kts,build.gradle.kts,gradle.properties,gradle/libs.versions.toml,gradlew*}`, модули `wishbone-core`, `wishbone-ui`, `wishbone-lottie`, `wishbone-rive`, `playground`.

**Interfaces — Produces (`:wishbone-core`, пакет `app.wishbone.core`):**
